# Aluguito 0.2.3 — portátil para Windows

## Abrir e atualizar

1. Se estiver usando a versão anterior, escolha **Sair do Aluguito** no menu do mascote ou no ícone perto do relógio.
2. Extraia **Aluguito-Portable-0.2.3.zip** para uma pasta de sua escolha e abra **Aluguito.exe** dentro dela. Não exige instalação, Node.js ou acesso de administrador. Mantenha todos os arquivos da pasta juntos.
3. Clique no personagem. O painel abre junto ao próprio mascote.
4. As configurações e a conversa da versão anterior são recuperadas do mesmo perfil do Windows. O modelo escolhido para esta atualização é `gemini-3.5-flash-lite`. Configurações antigas que ainda usam os modelos iniciais `gemini-2.5-flash` ou `gemini-3.5-flash` passam para essa versão leve; outros modelos personalizados são preservados.

O aplicativo é portátil; os dados ficam protegidos neste computador. Para levar o aplicativo a outro computador, copie a pasta inteira e configure sua chave e sua conta Google nele. Se mover a pasta e usar a opção de iniciar com o Windows, salve novamente essa opção para atualizar o caminho.

Esta é uma versão de teste sem assinatura digital. O Windows pode mostrar um aviso de editor não verificado. Os arquivos do projeto Explora, do jogo e o Pet do ChatGPT não são alterados.

## Usar o mascote

- O atalho do Pomodoro e o menu **•••** ficam em coluna à direita do mascote.
- **Tamanho do Aluguito** oferece Pequeno, Normal, Grande e Maior.
- Clique e arraste o próprio personagem para movê-lo. Um clique curto abre ou recolhe a conversa.
- Passe o mouse sobre o mascote e arraste a seta para redimensioná-lo. Ele começa menor nesta versão.
- A conversa começa ao lado esquerdo do Aluguito. Arraste o cabeçalho para posicionar somente a conversa, sem mover o mascote.
- Arraste as bordas e os cantos do painel para ajustar livremente largura e altura.
- No menu **•••**, use **Posição da conversa** para escolher esquerda, direita ou acima e **Tamanho da conversa** para os tamanhos prontos. As preferências são salvas.
- **Reposicionar no canto direito** recupera o mascote na tela principal.
- **Minimizar** oculta o mascote; o ícone perto do relógio permite mostrá-lo de novo.
- **Recolher conversa** fecha apenas o painel. **Sair do Aluguito** encerra também os lembretes.
- O painel aberto também pode ser redimensionado pelas bordas. Não há uma segunda janela de conversa nem barra de menus em inglês.

## Chave, modelo e data

Em **Ajustes → Conta Google → Gemini**, cole a chave do Gemini e use **Testar conexão**. Depois de salvar, o campo não revela a chave: mostra **Chave salva — digite aqui somente para trocar**. Salvar com o campo vazio mantém a chave atual. **Remover chave** é a ação que a apaga.

Você pode criar uma chave em [Google AI Studio](https://aistudio.google.com/apikey). Nenhuma chave está embutida no executável. A integração encontrada no Explora usa a credencial da Lovable, que não foi copiada para este aplicativo.

O Aluguito fornece data, hora e fuso do computador em cada pergunta. Para isso funcionar corretamente, o relógio e o fuso do Windows precisam estar corretos.

Em caso de erro 503 ou outros erros temporários do servidor, tenta novamente até três vezes, com espera progressiva, no mesmo modelo. Se a falha persistir, preserva a pergunta e a chave. Isso ajuda em falhas transitórias; não elimina uma indisponibilidade do Google. O modelo pode ser trocado em Ajustes.

## Pesquisa, formatação e imagens

**Pesquisar na web**, no campo de conversa, habilita a ferramenta Google Search do Gemini para aquela pergunta. Começa desmarcada para permitir conversar mesmo quando a pesquisa estiver sem cota. O modelo decide quando buscar. **Ajustes → Conta Google → Gemini → Permitir pesquisa na web** controla a disponibilidade geral. Uma resposta com resultados mostra fontes consultadas e, quando fornecidas, sugestões do Google.

Títulos, negrito, listas, links, tabelas, citações e blocos de código são exibidos com formatação. Links abrem no navegador. Conteúdo recebido é sanitizado e não pode executar scripts.

Com **Incluir imagens da pesquisa** ligado, o aplicativo solicita imagens à ferramenta e exibe imagens retornadas, com link para a fonte. Isso depende da capacidade do modelo e da disponibilidade dos resultados. Se o modelo recusar a ferramenta de imagens, tenta a pesquisa em texto e avisa. Não inventa URLs de imagens. Imagens removidas ou bloqueadas pelos sites podem não carregar.

Pesquisa e imagens usam as cotas e as condições do seu projeto Google; não são garantia de uso gratuito ilimitado. Se a cota da pesquisa acabar, desmarque a busca para continuar usando a conversa quando houver cota de geração disponível.

## Histórico como conversas separadas

- Use **＋** para iniciar uma conversa.
- Use o botão **☰** para buscar pelo título e reabrir uma anterior.
- Cada conversa pode ser renomeada ou excluída. A exclusão pede confirmação.
- A conversa da versão anterior aparece como **Conversa anterior**, com as mensagens preservadas.
- O histórico completo de cada conversa fica no computador. O contexto enviado ao modelo usa até as últimas 24 mensagens da conversa atual; conversas longas não são enviadas integralmente a cada pergunta.
- **Limpar conversa atual**, em Ajustes, apaga apenas as mensagens da conversa selecionada.

Não há sincronização de histórico entre computadores ou com a conta ChatGPT.

## Conectar Google pela primeira vez

A chave do Gemini não autoriza o acesso ao Gmail ou à agenda. Se esta instalação ainda não tiver uma credencial OAuth configurada, siga a configuração inicial do projeto Google:

1. [Crie um projeto no Google Cloud](https://console.cloud.google.com/projectcreate).
2. Ative **Gmail API** e **Google Calendar API** nesse projeto.
3. Configure a tela de consentimento OAuth com o nome Aluguito e os contatos solicitados pelo Google. Se o aplicativo estiver em teste, inclua o e-mail da conta que vai usá-lo como usuário de teste.
4. Em **APIs e serviços → Credenciais**, crie um **ID de cliente OAuth** do tipo **Aplicativo para computador / Desktop app**. Baixe seu JSON. Não use conta de serviço ou credencial de aplicação web.
5. No Aluguito, entre em **Ajustes → Conta Google → Conexão → Importar credencial JSON**, selecione o arquivo e clique em **Conectar Google**.
6. Escolha sua conta no navegador e autorize as permissões de leitura. O Aluguito exibirá o endereço conectado quando a API permitir consultar o perfil.

Os links de cada etapa também estão em **Ajustes → Conta Google → Conexão → Primeira conexão: passo a passo**. Depois que a configuração existir, o usuário só precisa autorizar sua conta no navegador.

Os escopos são somente leitura: `gmail.readonly` e `calendar.events.readonly`. Antes de distribuir para outras pessoas, o responsável precisa preparar a configuração de produção e a verificação dos escopos exigida pelo Google. Em modo de teste, autorizações podem expirar e exigir nova conexão.

Se ocorrer erro 403, confira as duas APIs, os usuários de teste e as permissões concedidas. A confirmação do fluxo real só é possível depois que essa credencial for criada e a conta autorizada.

## Consultar a conta e lembrar reuniões

As áreas **Agenda** e **E-mails** permitem consultar diretamente os dados. O chat também reconhece pedidos pessoais como **“Veja minha agenda de hoje”**, **“O que tenho amanhã?”** e **“Quais meus e-mails?”**. Nesses pedidos, consulta a conta conectada e apresenta os resultados diretamente no chat. O botão **Resumir prévia** usa o Gemini após confirmação. Sem conexão Google, pede para conectar a conta.

Agenda consulta a agenda principal. No chat, consultas como **hoje**, **amanhã** e **esta semana** limitam o período da busca. Gmail mostra assuntos, remetentes e prévias de até 15 mensagens por busca; o corpo completo abre no Gmail. O chat consulta a caixa de entrada. A área E-mails aceita filtros de busca do Gmail.

**Resumir prévia** pede confirmação antes de enviar assunto, remetente e prévia ao Gemini. Resumos e dados da conta são marcados como privados e excluídos do contexto das próximas perguntas que usam pesquisa web. Ao pedir resumos da sua conta no chat, os dados consultados são enviados ao Gemini para elaborar a resposta.

O aplicativo não envia e-mails, não altera mensagens e não cria ou modifica compromissos.

O Aluguito verifica reuniões a cada 30 segundos e notifica com a antecedência escolhida. Eventos cancelados ou de dia inteiro não geram lembrete. A notificação abre o link da reunião; sem link, abre a agenda. O computador precisa estar ligado, com internet, e o Aluguito rodando. O modo Não perturbe do Windows pode silenciar avisos. Reiniciar perto de uma reunião pode repetir um aviso. Não há envio de links por WhatsApp ou e-mail.

## Conectar seu servidor MCP depois, por OAuth

1. Em **Ajustes → Integrações**, clique em Adicionar MCP para um novo cadastro, dê um nome e informe o endereço completo do servidor, por exemplo `https://seu-projeto.com/mcp`.
2. Use a conexão HTTP padrão. Se o seu servidor usar o transporte antigo SSE, escolha essa compatibilidade na configuração avançada.
3. Clique em **Conectar MCP**. O Aluguito descobre a configuração OAuth e abre o navegador para login e autorização. Suporta PKCE, cadastro dinâmico quando oferecido pelo servidor e renovação de tokens pelo SDK oficial.
4. Se o seu provedor exigir cadastro prévio de aplicativo, registre um cliente público para desktop, com PKCE, e informe o ID do aplicativo no campo avançado. O retorno que deve ser autorizado é **http://127.0.0.1:35691/mcp/oauth/callback**. Não precisa colar sua senha no Aluguito.
5. Após conectar, escolha as ferramentas de consulta permitidas e salve os ajustes. Por padrão, nenhuma ferramenta fica liberada.
6. Quando seu servidor ganhar novas permissões ou ferramentas, use **Atualizar permissões**. O aplicativo recarrega o catálogo com a autorização existente. Ferramentas novas ficam desmarcadas; as que já foram selecionadas são preservadas enquanto estiverem disponíveis.
7. Na conversa, escolha o MCP pelo nome e marque **Usar projeto MCP** e faça sua pergunta sobre tarefas, prazos ou engajamento. O Gemini escolhe entre as ferramentas que você liberou. A busca pública na internet fica desativada nesse modo.

O catálogo mantém as classificações do servidor. As alterações suportadas são **criar_tarefa**, **mudar_status_tarefa**, **importar_posts_instagram** e **atualizar_metricas_instagram**. Elas precisam estar selecionadas e cada execução exige confirmação. O servidor continua aplicando as permissões da conta OAuth.

Os dados retornados pelas ferramentas são enviados ao Gemini para elaborar a resposta. Não são enviados ao Google Search. Tokens OAuth ficam no armazenamento protegido e não entram no contexto do modelo. A resposta indica quais consultas do projeto foram usadas.

**Desconectar MCP** fecha a conexão e remove as credenciais locais. Se o provedor oferecer um endereço de revogação, também tenta revogar o token; a autorização pode ser removida nas configurações do provedor. O fluxo completo foi testado contra um servidor local de teste com OAuth.

## Dados e desenvolvimento

Chave, tokens Google, configurações e conversas ficam em `cofre.bin`, protegido pela criptografia do Windows, no perfil local **Aluguito** em AppData. Essa proteção é para os dados em repouso, não contra todo software executado na mesma conta do Windows.

Perguntas vão diretamente à API do Google; não há servidor da Alugo Ideias recebendo esses dados. No plano gratuito, o Google pode usar o conteúdo enviado para melhorar seus produtos; evite informações confidenciais nessa modalidade. Imagens da pesquisa são carregadas dos sites de origem e links abrem no navegador.

O código-fonte exige Node.js e npm:

```
npm ci
npm test
npm run smoke
npm start
npm run dist
```

O teste de interface usa um perfil temporário com uma chave fictícia. Verifica armazenamento protegido, chave preservada após recarregar, formatação segura, histórico, janela única e recolhimento. Os testes não usam sua chave nem acessam contas reais. O fluxo OAuth também é testado localmente com respostas simuladas. Isso não substitui o teste real depois da configuração Google.
